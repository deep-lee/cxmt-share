Lesson 1: Setup Chrome DevTools MCP in OpenCode

Get your AI agent driving a real browser in 5 minutes.

What You'll Learn

By the end of this lesson, you'll have chrome-devtools-mcp running inside opencode and be able to ask your AI agent to navigate a web page, click elements, and take screenshots.

How It Works

chrome-devtools-mcp is an official MCP server maintained by the Chrome DevTools team. It acts as a bridge:

You (in opencode) → MCP Server → Chrome DevTools Protocol → Chrome Browser

When you ask opencode to "go to example.com and take a screenshot", opencode calls the MCP server, which sends CDP commands to Chrome, which executes them and returns results.

Key concept: The MCP server automatically launches Chrome for you. No manual browser setup needed (unless you want to connect to an existing browser).

Step 1: Configure opencode

Add this to your ~/.config/opencode/opencode.json file (create it if it doesn't exist):

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "chrome-devtools": {
      "type": "local",
      "command": ["npx", "-y", "chrome-devtools-mcp@latest"]
    }
  }
}

This tells opencode to start the chrome-devtools-mcp server as a subprocess. The -y flag auto-confirms the npx install.

Step 2: Restart opencode

Close and restart opencode. You should see the MCP server start up. You can verify it's connected by checking for the MCP tools in your agent's tool list.

Step 3: Test It

Ask your opencode agent a prompt like:

Go to https://example.com and take a screenshot

If everything is set up correctly, opencode will:

  1. Launch Chrome (you'll see a browser window appear)
  2. Navigate to example.com
  3. Take a screenshot and show it to you
Tip: If you want to keep browser state (cookies, sessions) between sessions, remove the --isolated flag. By default, the server uses a persistent profile at ~/.cache/chrome-devtools-mcp/chrome-profile-stable.

What Each Tool Does

The server exposes 40+ tools. The ones you'll use most:

Tool What it does
navigate_page Go to a URL
take_snapshot Get page DOM with element IDs
click Click an element by CSS selector or UID
fill Type text into an input
take_screenshot Capture a PNG screenshot
evaluate_script Run JS in the page
list_console_messages Read console logs

See the glossary for the full list.

Your Task

Goal: Get the setup working and run your first automation.

  1. Add the MCP config to your opencode.json
  2. Restart opencode
  3. Ask your agent to navigate to a site and take a screenshot
  4. Try asking it to click a link on the page

Once you see the screenshot, you've succeeded. 🎉
