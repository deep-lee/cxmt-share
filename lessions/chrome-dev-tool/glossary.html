Chrome DevTools MCP — Glossary

Core Concepts

CDP (Chrome DevTools Protocol)
The wire protocol that allows tools to inspect, debug, and control Chromium-based browsers. All MCP tools in chrome-devtools-mcp communicate via CDP commands under the hood.
MCP (Model Context Protocol)
An open protocol that lets AI assistants (like opencode) connect to external tools and data sources. chrome-devtools-mcp is an MCP server.
MCP Server
A process that exposes tools to an MCP client (opencode). Configured in opencode.json under the mcp key.
opencode.json
The configuration file for opencode. Located at ~/.config/opencode/opencode.json. MCP servers and plugins are configured here.
Remote Debugging Port
A port (default 9222) on which Chrome listens for CDP connections. Enabled by launching Chrome with --remote-debugging-port=9222.
WebSocket (WS) Endpoint
A URL like ws://127.0.0.1:9222/devtools/browser/<id> that the MCP server uses to connect to a running Chrome instance.
Page / Target
Each browser tab or window is a "target" in CDP. Tools like list_pages enumerate these targets.
Snapshot / AX Tree
An accessibility-tree snapshot of the page DOM with unique IDs ([uid] markers). Used by take_snapshot to identify clickable/fillable elements.

Key Tools

navigate_page
Navigates the current page to a URL. Waits for the page to load before returning.
click
Clicks an element identified by a CSS selector or a snapshot UID.
fill
Fills an input field identified by CSS selector or snapshot UID.
take_snapshot
Captures the accessibility tree of the current page, returning elements with [uid] identifiers for use by click and fill.
take_screenshot
Captures a PNG screenshot of the current page.
evaluate_script
Executes arbitrary JavaScript in the page context and returns the result.
list_console_messages
Gets console output (log, warn, error) from the page.
list_network_requests
Lists network requests made by the page.
fill_form
Fills multiple form fields at once from a dictionary of {selector: value} pairs.
performance_start_trace / performance_stop_trace
Records a Chrome DevTools performance trace for analysis.
list_pages
Lists all open pages/tabs in the browser.
new_page / close_page
Creates or closes a browser tab.

Configuration Flags

--headless
Run Chrome without a visible UI window.
--isolated
Use a temporary Chrome profile that is cleaned up when the browser closes.
--autoConnect
Automatically connect to a running Chrome instance (Chrome 144+).
--slim
Expose only 3 core tools (navigate, evaluate, screenshot) for basic tasks.
--channel
Choose Chrome channel: stable, beta, dev, or canary.
--userDataDir
Path to Chrome's user data directory (preserves cookies, sessions).
--viewport
Initial viewport size, e.g. 1280x720.
