Lesson 6: Advanced Automation Patterns

Dialogs, file uploads, keyboard shortcuts, drag-and-drop, and browser extensions.

What You'll Learn

By the end of this lesson, you'll be able to handle browser dialogs (alert/confirm/prompt), upload files, use keyboard shortcuts, perform drag-and-drop, and install Chrome extensions during automation.

New Tools

Tool What it does
handle_dialog Accept or dismiss a browser dialog (alert, confirm, prompt)
upload_file Upload a file by selecting it in a file picker
type_text Type text character by character into a focused element
press_key Press a key or combo (Ctrl+A, Tab, Escape, etc.)
drag Drag one element onto another
click_at Click at x,y coordinates (requires --experimentalVision)
install_extension Install a Chrome extension from the store or unpacked
list_extensions List installed extensions
uninstall_extension Remove an extension by ID

Knowledge: Handling Dialogs

Browser dialogs (alert(), confirm(), prompt()) block the page until dismissed. The automation agent can't interact with the page while a dialog is open — it must handle the dialog first:

1. click a button that triggers alert()
2. handle_dialog (action: "accept")
     → dialog is dismissed, page interaction resumes
// For prompt dialogs, you can provide text:
handle_dialog (action: "accept", promptText: "my response")
Tip: The agent detects open dialogs automatically. You don't usually need to ask for handle_dialog explicitly — just tell the agent what to do and it will handle the dialog when it appears.

Knowledge: File Uploads

Uploading a file requires two things: a file input element and a local file path:

1. take_snapshot → find the file input element UID
2. upload_file (uid: [7], filePath: "/path/to/file.pdf")
     → file is selected and ready for submission
Important: The file path is from your local machine. The agent reads the file from your filesystem and sends it to the browser. Use absolute paths.

Knowledge: Keyboard & Type Actions

press_key vs type_text

press_key is for single keys or shortcuts (Enter, Tab, Ctrl+A, Ctrl+Shift+R). type_text is for typing character by character into the currently focused element — useful when fill doesn't trigger the right events:

// Fill vs type comparison:
fill (uid: [5], value: "hello")       → sets value directly
type_text (text: "hello")              → types each keystroke

// Keyboard shortcuts:
press_key (key: "Control+A")           → select all
press_key (key: "Delete")              → clear
press_key (key: "Control+V")           → paste
When to type_text: Some sites (especially SPAs) listen for keydown/keyup events that fill doesn't trigger. If fill works but the page doesn't react, try type_text instead.

Knowledge: Drag-and-Drop

Drag an element from one location onto another:

1. take_snapshot → find source element UID and target element UID
2. drag (from_uid: [3], to_uid: [12])
     → element [3] is dropped onto element [12]

Common use cases: reorderable lists, kanban boards, file upload zones.

Coordinate-based clicks

If you need to click at a specific pixel position (e.g., on a canvas):

// Requires server config: --experimentalVision
click_at (x: 450, y: 300)

Enable this by adding "--experimentalVision" to your server args in opencode.json.

Knowledge: Extensions

You can install Chrome extensions during automation. Extensions persist as long as the profile persists:

install_extension (id: "cjpalhdlnbpafiamejdnhcphjbkeiagm")
  → installs uBlock Origin from the Chrome Web Store
// List installed to find extension IDs:
list_extensions → returns IDs and names
Note: The extensions feature requires the MCP server to use a pipe connection. It doesn't work with --autoConnect, --browserUrl, or --wsEndpoint until Chrome 149+.

Skill: Practice Tasks

Task A: Dialog handling

Go to https://alert-test-site (or any page with a JS alert),
click the button that triggers an alert, and accept it.
Then confirm the dialog is gone by taking a screenshot.

Task B: File upload

Go to https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_input_type_file,
upload any small file from your desktop, and take a screenshot
showing the file was selected.

The agent will need to navigate into the iframe or use the file input element's UID.

Task C: Keyboard shortcut

Go to https://example.com, take a screenshot,
then press Ctrl+A (select all) followed by Ctrl+C (copy).
Use evaluate_script to verify nothing broke.

Task D: Type text into a rich editor

Go to any page with a textarea or rich text editor,
click it to focus, then type_text "Hello, world!"
and take a screenshot.
