CimiCode 是什么？

CimiCode 是一个开源 AI 编码代理（AI Coding Agent）。

你可以把它理解为一个能操作电脑的 AI 助手——你告诉它你想做什么，它就能理解你的意图，自动执行操作。

不只是聊天机器人：普通的 AI 只能"回答"问题。CimiCode 能操作——读写文件、运行命令、控制浏览器、调用各种工具。

它能做什么？

  • 写代码/修 Bug — 理解项目结构，自动生成或修改代码
  • 操作文件 — 创建、编辑、搜索文件
  • 运行命令 — 帮你执行各种系统命令
  • 控制浏览器 — 自动填表、截图、提取数据
  • 连接工具 — 通过 MCP 协议连接 浏览器、数据库、测试平台等

四种使用方式

🖥 终端 (TUI)

命令行界面，最灵活。运行 cimicode 即可启动。适合开发者日常使用。

🪟 Desktop 桌面应用

重点推荐。图形界面，无需命令行。适合所有同事使用。

🌐 Web 浏览器

浏览器中直接使用，同一网络下其他设备也可访问。无需安装客户端。

🔌 IDE 扩展

VS Code / Cursor / Zed 等编辑器中直接使用。适合开发同事。

CimiCode Desktop (桌面应用)

安装方式

  1. 填写问卷申请 — 提交使用申请，等待审核
  2. 审核通过后 — 打开长鑫安全助手 → 软件管理
  3. 搜索安装 — 搜索 "Cimi"，点击安装即可

主要特性

  • 图形化界面 — 所见即所得，无需记住命令
  • 多会话管理 — 同时开启多个任务
  • 自动连接 Token Plan — 自动接入智多鑫 Token Plan，即开即用
  • 文件引用 — 直接在对话中引用文件
目前为 Beta 版本，但功能已完善，适合日常使用。正式版将持续更新。

界面中可以看到技能中心和我的技能入口，接下来我们就来介绍 Skills（技能）到底是什么。

什么是 Skills？

Skills（技能）是 CimiCode 的一种可复用指令集。你可以把 Skills 理解为——提前准备好的"任务模版"。

打个比方：就像你在工作中使用的 SOP（标准作业程序）。不同的是，这个 SOP 是写给 AI 看的，AI 会按照 SOP 的步骤自动执行。

Skills 的工作原理

步骤说明
1. 编写在项目中创建 .cimicode/skills/<名称>/SKILL.md 文件
2. 定义在文件中描述该技能的用途、步骤和注意事项
3. 发现CimiCode 启动时自动扫描并注册所有可用技能
4. 调用自动调用：Agent 根据对话内容自动选择并加载合适的技能
手动调用：通过 / 命令主动触发指定技能

Skills 详解

Skill 文件结构

📁 .cimicode/skills/
   └── 📁 code-review/         # 技能名称
        └── 📄 SKILL.md        # 技能定义文件

SKILL.md 示例

---
name: code-review
description: Review code for quality and best practices
---

## What I do
- Review code changes for potential issues
- Suggest improvements

## When to use
Use this when reviewing pull requests.

存放位置

  • 项目级：.cimicode/skills/<名称>/SKILL.md
  • 全局：~/.cimi/cimicode/skills/<名称>/SKILL.md
关键：Skill 名称必须和目录名一致，只支持小写字母、数字和单连字符。
