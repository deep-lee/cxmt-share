讲师备注 — CimiCode Desktop & Skills 培训

总时长：30 分钟 | 受众：质量可靠性保证部（非技术背景）

总体准备

会前准备清单

事项说明
安装 CimiCode Desktop提前在长鑫安全助手 → 软件管理中安装好最新版 Desktop
准备 Demo 数据创建一个包含模拟测试数据的 CSV 文件
检查网络确保演示电脑可以正常联网（模型调用需要网络）
准备备用方案如网络不通，准备录屏视频作为备用
测试投影确保投影或屏幕共享正常，字体大小合适
打开课件提前在浏览器中打开 HTML 课件

演讲风格建议

  • 多用比喻：把 AI 比作"实习生"或"助手"，不要用技术术语
  • 避免深入技术细节：不要讲 MCP 协议、JSON 配置等技术概念，除非有人问
  • 强调"自然语言"：反复强调"你只需说人话，AI 就能理解"
  • 互动：多问"你们平时做这个工作要多久？"激发共鸣
  • 管理期望：说明 AI 不是万能的，但可以大幅提升效率

逐页演讲脚本

Slide 1: 封面 (1 分钟)

讲稿："大家好！今天给大家带来一个非常有意思的工具——CimiCode。我先做个简单的自我介绍，我是 XXX（你的名字），来自 XXX 部门。今天的培训大约 30 分钟，我会先介绍 CimiCode 是什么，然后重点介绍 Desktop 桌面版的使用，最后做一个现场演示。"

要点：轻松开场，建立亲切感。强调"30 分钟很短，干货满满"。

Slide 2: 议程 (0.5 分钟)

讲稿："今天的安排是这样的——先简单介绍 CimiCode 是什么、能做什么，然后介绍三种使用方式，重点是我们今天的主角 Desktop，再介绍 Skills 这个概念，最后看一些和我们质量工作相关的应用场景和现场演示。"

Slide 3: 为什么了解 CimiCode (1.5 分钟)

讲稿："首先，大家可能会问——我为什么要了解这个东西？我给大家几个数据：CimiCode 是 GitHub 上最热门的开源 AI 项目之一，有超过 16 万颗星标。它不是一个普通的聊天机器人，而是一个能真正干活的 AI 助手。最重要的是，它是免费的，而且注重隐私安全——你的代码和数据不会被上传到别人的服务器。"
提示：这里可以问一下："大家听说过 ChatGPT 或类似的 AI 工具吗？" 建立对比。

Slide 4: CimiCode 是什么 (2 分钟)

讲稿："简单来说，CimiCode 是一个 AI 助手，但它比普通的聊天机器人更强大——它不仅能回答问题，还能实际操作你的电脑。比如你告诉它'帮我把这个 Excel 文件里的数据整理一下，生成一个报告'，它就能自动读取文件、分析数据、写出报告。它的能力包括：写代码、改文件、搜索代码、运行命令、控制浏览器等等。"
提示：用具体例子说明"能做什么"比抽象描述更有说服力。

Slide 5: 四种使用方式 (2 分钟)

讲稿："CimiCode 有四种使用方式。终端方式最适合开发者。Desktop 桌面应用是今天的主角——它提供图形界面，你不需要记任何命令，像使用普通软件一样。Web 版可以在浏览器中直接使用，无需安装。IDE 扩展是在 VS Code 等编辑器里直接使用。对于质量部门的同事来说，我推荐 Desktop 和 Web 版本。"
提示：这里可以打开 Desktop 应用让观众看一眼界面，增加直观感。

Slide 6: Desktop 桌面应用 (1 分钟)

讲稿："Desktop 版本目前是 Beta 阶段，但功能已经很完善了。安装非常简单——先填写问卷申请，审核通过后在长鑫安全助手的软件管理中搜索 Cimi 安装即可。"

Slide 7: Desktop 界面导览 (2 分钟)

讲稿："我们打开 Desktop 来看一下界面。主界面分为几个区域——中间是对话区，AI 的回复和操作结果会显示在这里。底部是输入框，在这里用中文输入你的需求。左边是会话列表，可以同时开多个任务。你还可以拖拽文件到窗口，AI 就能直接读取。右上角可以切换模型，已经自动接入了智多鑫 Token Plan。

两个重要功能：按 Tab 键可以在 Plan 和 Build 模式间切换——Plan 模式 AI 只有分析不做修改，Build 模式可以执行所有操作。另外操作默认自动执行权限，不需要每一步都确认，保证流畅体验。

大家注意界面上的 技能中心 和 我的技能，这就是我们接下来要介绍的 Skills（技能）的入口。"
提示：这是与听众互动的好机会——"大家看一下屏幕，这就是你们安装后打开会看到的界面。很简单对吧？"

Slide 7: Skills 是什么 (3 分钟)

讲稿："接下来介绍一个非常重要的概念——Skills，技能。你可以把 Skills 理解为提前给 AI 写好的'作业指导书'。比如我们有一个标准的数据分析流程——第一步读数据、第二步检查异常值、第三步生成图表、第四步写报告。你把这些步骤写成一份 SKILL.md 文件，以后 AI 看到类似任务，就会自动按这个流程执行。这就相当于把你的工作经验教给了 AI。"
注意：这是最抽象的概念，非技术同事可能不太好理解。尽量用"SOP"或"作业指导书"作比喻。

Slide 8: Skills 详解 (2 分钟)

讲稿："Skills 的文件结构很简单——一个文件夹，里面放一个 SKILL.md 文件。文件头写基本信息（名称、描述），正文写具体要 AI 怎么做。它可以在项目中使用，也可以全局使用。调用有两种方式：一是 Agent 根据你的问题自动选择合适的技能；二是通过 / 命令手动触发。需要注意的是，技能名称必须用小写字母和连字符。"
提示：快速展示代码示例，但不必逐行讲解。强调"看起来很复杂，但实际上只需要写几行字"。

Slide 9: 常用 Skills 示例 (2 分钟)

讲稿："我们来看一些实际可用的 Skills 示例。grill-me 可以对你的方案进行深度拷问，帮你提前发现漏洞。frontend-design 是前端组件设计助手。pptx 和 xlsx 分别用来操作 PPT 和 Excel 文件。lark 技能可以连接飞书，操作文档和表格。workspace 是我们长鑫内部的工作区 Skill，集成了常用的内部工作流。这些 Skills 开箱即用，让 AI 能更懂我们的需求。"
提示：快速过一遍即可，不用每个都详细展开。突出"开箱即用"和"长鑫内部 workspace"两个重点。

Slide 10: 质量可靠性应用场景 (3 分钟)

讲稿："讲完了概念，我们来聊聊和我们工作相关的地方。我们质量可靠性部门每天要做很多重复性工作——数据分析、缺陷追踪、报告编写、文档审核等等。CimiCode 可以在这些方面帮到我们。比如：

数据分析：AI 直接读取测试数据，自动计算合格率、绘制趋势图。
缺陷追踪：AI 连接到我们的缺陷管理系统，查询、分类、汇总。
报告生成：我们只要提供数据和模板，AI 就能生成格式规范的质量报告。
文档审核：给 AI 一份检查清单，它可以逐项核对文档内容。

这些都是实实在在能提高效率的场景。"
提示：这里可以和听众互动，问"你们平时最花时间的重复性工作是什么？"

Slide 11: Demo 演示 (8 分钟)

讲稿："接下来是大家最期待的环节——现场演示。我会用 CimiCode Desktop 演示一个质量数据分析的场景。具体步骤请参考 Demo 脚本。整体来说，你会看到我用自然语言告诉 AI 我想做什么，AI 自动完成整个流程。"
关键：Demo 是最重要的环节，务必演练熟练。
准备好以下应急预案：
- 如果网络卡顿：提前打开所有需要的页面
- 如果 AI 回答不理想：准备一个"刚才的回答不太对，我们换个方式问"的过渡
- 如果完全不行：准备录屏视频

Slide 12: 总结 + Q&A (2 分钟)

讲稿："最后总结一下——CimiCode 是一个开源的 AI 助手，Desktop 桌面版让我们可以轻松使用。Skills 技能让我们可以把工作经验教给 AI。在质量可靠性工作中，数据分析、报告生成、缺陷追踪等场景都可以受益。希望大家回去后可以下载试用。如果有任何想法或需求，欢迎随时交流。现在进入 Q&A 环节。"
Q&A 常见问题预判：
- "这个安全吗？" → 强调数据隐私：不存储代码，可离线使用
- "需要学编程吗？" → 不需要，自然语言即可
- "要花多少钱？" → 有免费模型可用
- "能帮我们做 XX 吗？" → 多数场景可以，具体评估
