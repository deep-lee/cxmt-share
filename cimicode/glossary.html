OpenCode 术语表

核心概念

OpenCode
开源 AI 编码助手（Coding Agent）。支持终端、桌面应用和 IDE 扩展三种使用方式。160K+ GitHub Stars，每月 750 万开发者使用。
OpenCode Desktop
OpenCode 的桌面版应用（Beta 阶段）。支持 macOS、Windows、Linux。提供图形化界面，无需操作终端即可使用 AI 编码助手。
Agent（代理）
OpenCode 中的 AI 助手。内置有 Build（构建）、Plan（计划）两个主代理，以及 General（通用）、Explore（探索）、Scout（侦察）三个子代理。用户也可自定义代理。
Build Agent（构建代理）
OpenCode 的默认主代理，拥有所有工具权限，适合日常开发和代码修改。
Plan Agent（计划代理）
只读的主代理，用于分析代码和制定计划，不能修改文件。适合代码审查和方案设计。
Skill（技能）
通过 SKILL.md 文件定义的可复用指令集。Agent 可通过内置 skill 工具按需加载。支持项目级和全局级两种存放位置。
MCP (Model Context Protocol)
模型上下文协议。一种开放协议，让 AI 助手连接到外部工具和数据源。OpenCode 支持本地和远程 MCP 服务器。
MCP Server (MCP 服务器)
向 AI 助手暴露工具的进程。在 opencode.json 中配置，启动后自动可用。
opencode.json
OpenCode 的配置文件。支持 JSON/JSONC 格式，可用于配置模型、MCP 服务器、代理、工具权限等。支持全局 (~/.cimi/cimicode/) 和项目级两种配置。
TUI (Terminal User Interface)
OpenCode 的终端用户界面。通过运行 opencode 命令启动，提供交互式聊天界面。
Web 界面
通过 opencode web 命令启动的浏览器界面。同一网络下的其他设备可访问。

技能 (Skills) 相关

SKILL.md
技能定义文件。包含 YAML 前置元数据（frontmatter）和 Markdown 内容。存放在 .cimicode/skills/<name>/ 或 ~/.cimi/cimicode/skills/<name>/ 目录下。
Frontmatter（前置元数据）
SKILL.md 文件开头的 YAML 配置块，包含 name（必填）、description（必填）、license（可选）、metadata（可选）等字段。
skill 工具
OpenCode 的内置工具，用于列出和加载可用技能。Agent 会自动识别到合适的 skill 并加载使用。
技能权限
通过 opencode.json 中的 permission.skill 配置，控制哪些技能可以被加载。支持通配符模式（如 internal-*）。

代理 (Agents) 相关

Primary Agent（主代理）
直接与用户交互的代理。可通过 Tab 键在多个主代理间切换。Build 和 Plan 是内置的主代理。
Subagent（子代理）
可由主代理调用或通过 @ 提及手动调用的专业化代理。General, Explore, Scout 是内置子代理。
@ 提及
在对话中使用 @+代理名 来手动调用子代理。例如 @explore 来探索代码库。
权限 (Permission)
控制代理行为的安全设置。支持 allow（允许）、ask（询问）、deny（禁止）三级权限，可精确控制到具体工具甚至 bash 命令。

配置与使用

/init
初始化命令。让 OpenCode 分析项目结构并生成 AGENTS.md 文件。
/undo / /redo
撤销/重做命令。可撤销 AI 助手上一次的修改。需项目为 Git 仓库。
/share
分享当前对话。生成链接后可与团队成员共享。
/compact
压缩当前对话上下文。当对话太长时可清理压缩。
@ 文件引用
在消息中使用 @+文件名 模糊搜索并引用项目文件。
Tab 键切换
在主代理间切换。Build（构建模式）→ Plan（计划模式）→ Build... 循环切换。

Chrome DevTools MCP 工具

CDP (Chrome DevTools Protocol)
允许工具检查、调试和控制基于 Chromium 的浏览器的有线协议。
navigate_page
导航当前页面到指定 URL。
click
点击页面上的元素。
fill / fill_form
填充表单输入框。
take_snapshot
获取页面无障碍树快照，返回带 uid 标识的元素。
take_screenshot
截取页面截图。
evaluate_script
在页面上下文中执行 JavaScript。
